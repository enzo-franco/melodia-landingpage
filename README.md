# Melodia: Sua Música, Sua Forma

Landing page de um aplicativo de música **conceitual**, desenvolvida para a disciplina de Front-end Design. A página apresenta benefícios, funcionalidades e depoimentos ilustrativos, além de um formulário de contato demonstrativo.

## Tecnologias

- HTML5 para a estrutura da página;
- Tailwind CSS por CDN para estilos e responsividade, com classes no próprio HTML;
- CSS3 por meio das classes utilitárias do Tailwind;
- Font Awesome para ícones;
- Google Fonts (Manrope) para a tipografia;
- JavaScript básico no arquivo `app.js` apenas para abrir o menu mobile, alternar o modo escuro, iniciar o áudio e mostrar a resposta do formulário.

## Como abrir

Abra `index.html` no navegador. É preciso estar conectado à internet para carregar Tailwind, os ícones e a fonte. Não há instalação nem servidor obrigatório. 

## Organização

- `index.html`: todas as seções e classes Tailwind;
- `app.js`: interações básicas;
- `assets/app-melodia.png`: imagem demonstrativa do aplicativo;
- `assets/perfis.png`: retratos ilustrativos dos depoimentos.
- `assets/azimuth.mp3`: faixa de demonstração reproduzida pelo player nativo do HTML.


**Privacidade:** o formulário é uma simulação. Nome e e-mail não são enviados, salvos nem compartilhados. O aplicativo, os perfis e os depoimentos da página são ilustrativos.
